# 🔐 React Authentication & Form Validation

Ushbu loyiha React va zamonaviy CSS yordamida yaratilgan to'laqonli autentifikatsiya (Login / Register) va formalar validatsiyasi tizimi.

## 🚀 Texnologiyalar

- **React 19**
- **React Router DOM v7**
- **Axios**
- **Custom Form Validation**
- **Vite**

## 🌟 Imkoniyatlar

- Login va Registratsiya sahifalari
- Email, parol va telefon raqamlari uchun real-vaqt validatsiyasi
- Xatolik xabarlarini foydalanuvchiga qulay ko'rsatish
- Vercel uchun deploy sozlamalari (`vercel.json`)

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build
npm run build
```
